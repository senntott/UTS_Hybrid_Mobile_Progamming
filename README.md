# SIMOBILE — Aplikasi Kasir Toko

Aplikasi kasir toko berbasis Ionic dan Angular. Data produk, keranjang, dan transaksi disimpan secara lokal di browser menggunakan LocalStorage.

## Fitur

- Dashboard jumlah produk, transaksi hari ini, dan produk terlaris
- Daftar produk dengan pencarian
- Detail produk, harga, dan stok
- Tambah, edit, dan hapus produk
- Form produk dengan validasi
- Keranjang belanja dan checkout
- Popup konfirmasi pembayaran berhasil
- Riwayat dan detail transaksi
- Profil toko, pengaturan tema, dan halaman About
- Animasi pada kartu produk dan pesan keranjang

## Teknologi

- Ionic
- Angular
- TypeScript
- LocalStorage

## Persiapan

Pastikan Node.js dan Ionic CLI sudah terpasang. Buka terminal di folder project yang berisi file `package.json`.

## Cara menjalankan

Jalankan perintah berikut satu per satu:

```bash
cd simobile
```

Kemudian install seluruh dependency:

1. Download file ZIP project SIMOBILE.
2. Extract file ZIP tersebut.
3.Buka terminal pada folder project SIMOBILE.
4. Pastikan posisi terminal berada di folder yang berisi file package.json.
5. Jalankan perintah berikut satu per satu:
npm install
```
